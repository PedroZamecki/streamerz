Streamerz for Linux

Version @VERSION@. Each way below keeps Streamerz up to date with the rest of your system.

Flatpak

Any distribution. Updates come with your other Flatpak apps (GNOME Software, Discover, or flatpak update).

flatpak install --user https://pedrozamecki.github.io/streamerz/streamerz.flatpakref

Or open the .flatpak file from the latest release: it adds the same updates.

Debian, Ubuntu, Linux Mint

Download Streamerz-linux-x86_64.deb from the latest release and install it. It adds this repository, so apt upgrade updates Streamerz.

sudo apt install ./Streamerz-linux-x86_64.deb

Fedora, openSUSE

The package adds this repository, so dnf upgrade or zypper update updates Streamerz.

sudo dnf install https://github.com/PedroZamecki/streamerz/releases/latest/download/Streamerz-linux-x86_64.rpm

Arch Linux

Trust the key once, then add the repository to /etc/pacman.conf.

curl -fsSL https://pedrozamecki.github.io/streamerz/streamerz.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key @FINGERPRINT@
[streamerz]
Server = https://pedrozamecki.github.io/streamerz/arch
sudo pacman -Sy streamerz

AppImage, or the program alone

Streamerz-linux-x86_64.AppImage and Streamerz-linux-x86_64 on the latest release run from anywhere and update themselves (Settings, Updates).
