# Integrations / VTube Studio (sub-actions)

VTube Studio model, hotkey, tint and expression controls. None of these run in Streamerz yet.

## Load Model

- Kind: sub-action
- Code: 12001
- Type: VTubeStudioLoadModel
- Category: Integrations/VTube Studio
- Needs: VTube Studio (not used yet)

Loads a VTube Studio model.

### Fields

None.

### Arguments

None set.

### Notes

- Not done in Streamerz yet: the type is known and kept, but nothing runs it.
