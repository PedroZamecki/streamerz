# Meld Studio / Layers (sub-actions)

The layers of a Meld Studio scene: visibility, text, media sources and browser URLs. Streamerz has the types for these, but doesn't run them yet.

## Set Layer Visibility State

- Kind: sub-action
- Code: 41006
- Type: MeldStudioSetLayerVisibilityState
- Category: Meld Studio/Layers
- Needs: nothing (not run yet)

Shows or hides a layer in a scene.

### Fields

None.

### Arguments

None set.

### Notes

- Not done in Streamerz yet: the type is known and kept, but nothing runs it.
