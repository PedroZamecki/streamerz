# Elgato / Camera Hub (sub-actions)

Actions for Elgato Camera Hub, the app that controls Elgato webcams, EpocCam and the teleprompter (Prompter).

## Set Contrast

- Kind: sub-action
- Code: 14301
- Type: ElgatoCameraHubWebcamSetContrast
- Category: Elgato/Camera Hub/Webcam
- Needs: Elgato Camera Hub (not wired up yet)

Sets the contrast of an Elgato webcam in Camera Hub.

### Fields

None.

### Arguments

None set.

### Notes

- Not done in Streamerz yet: the type is known and kept, but nothing runs it.
- The type keeps these settings: `adjustment`, `contrast`.
