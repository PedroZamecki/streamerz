# Integrations / VoiceMod (sub-actions)

VoiceMod voice changer, mute and soundboard controls. None of these run in Streamerz yet.

## Get Current Voice

- Kind: sub-action
- Code: 5001
- Type: VoiceModGetCurrentVoice
- Category: Integrations/VoiceMod
- Needs: the VoiceMod app (not used yet)

Gets the voice that VoiceMod has selected.

### Fields

None.

### Arguments

None set.

### Notes

- Not done in Streamerz yet: the type is known and kept, but nothing runs it.
- When it reaches the engine, Streamerz logs it once and skips it.
