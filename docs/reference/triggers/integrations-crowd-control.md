# Integrations / Crowd Control (triggers)

Triggers for Crowd Control, the app that lets viewers send effects to a game: game sessions, effect requests and results, timed effects and coin exchanges.

## Game Session Start

- Kind: trigger
- Code: 20001
- Type: CrowdControlGameSessionStart
- Category: Integrations/Crowd Control
- Needs: Crowd Control (not wired up yet)

Meant for the Game Session Start event of Crowd Control, when a game session begins.

### Fields

None.

### Arguments

None set.

### When

Never, for now. Streamerz doesn't fire this yet.

### Notes

- Streamerz doesn't fire this yet.
