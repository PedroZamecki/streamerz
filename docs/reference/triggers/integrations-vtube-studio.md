# Integrations / VTube Studio (triggers)

Triggers for VTube Studio, the app that shows VTuber models: model, background, hotkey, animation, tracking and connection events.

## Model Loaded

- Kind: trigger
- Code: 19001
- Type: VTubeStudioModelLoaded
- Category: Integrations/VTube Studio
- Needs: VTube Studio (not wired up yet)

Meant for the Model Loaded event of VTube Studio, when a model is loaded.

### Fields

None.

### Arguments

None set.

### When

Never, for now. Streamerz doesn't fire this yet.

### Notes

- Streamerz doesn't fire this yet.
