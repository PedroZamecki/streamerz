# Elgato / Wave Link (triggers)

Triggers for Elgato Wave Link, the audio mixer app: output, input and microphone changes, filters and the connection.

## Output Switched

- Kind: trigger
- Code: 21001
- Type: ElgatoWaveLinkOutputSwitched
- Category: Elgato/Wave Link/Outputs
- Needs: Elgato Wave Link (not wired up yet)

Meant for the Output Switched event of Elgato Wave Link, when an output is switched.

### Fields

None.

### Arguments

None set.

### When

Never, for now. Streamerz doesn't fire this yet.

### Notes

- Streamerz doesn't fire this yet.
